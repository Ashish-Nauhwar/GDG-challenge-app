# Gem - Programming Quiz & Learning App

**Gem** is an interactive Android application designed to help developers test and improve their programming knowledge. It features quizzes on various programming domains, gamification elements to keep users engaged, and tools to review past mistakes.

## 🚀 Features

* **Multiple Domains**: Practice your skills in **DSA**, **JavaScript**, **Kotlin**, **Java**, and **Python**.
* **Customizable Quizzes**: Choose the number of questions per session (ranging from 5 to 30 questions).
* **Gamification**:
    * **XP Tracking**: Earn experience points as you answer questions correctly.
    * **Daily Streaks**: Maintain a daily learning streak to stay motivated.
* **Mistake Vault**: Review questions you've answered incorrectly in the past to reinforce learning.
* **Quiz Battle**: Engage in a battle mode to test your speed and accuracy.
* **Domain Statistics**: View your attempts and accuracy rate for each programming domain.
* **Dark & Light Theme**: Built-in support for system theme following, or manual toggle between light and dark modes.

## 🛠 Tech Stack

* **Language**: [Kotlin](https://kotlinlang.org/)
* **Platform**: Android SDK (Min SDK 24, Target SDK 37)
* **UI**: Android XML Views & Material Components
* **Storage**: `SharedPreferences` (for tracking streaks, XP, mistakes, and theme preferences)
